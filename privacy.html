Privacy Policy

Last updated: 3 November 2026

This page describes the privacy practices for the Rclone Cloud Backup configuration described on this website. It is an informational page for a backup workflow operated by its account owner; it is not a hosted backup service.

Information handled by the backup workflow

When the account owner runs rclone, the software may access file names, folder structures, file contents, and account or storage metadata needed to perform the configured copy or synchronization tasks. The exact information accessed depends on the folders, commands, and permissions selected by the account owner.

How information is used and transferred

Information is accessed to copy or synchronize the selected files between the cloud storage accounts configured by the account owner. Depending on the storage providers and operation, file data may be transferred directly between providers or through the account owner's device.

Credentials and access tokens

Rclone stores its configuration and authorization tokens in a configuration file on the device where it is configured, unless the account owner chooses another storage arrangement. The account owner is responsible for protecting that device and configuration file. Credentials and tokens should never be published in this website's repository or shared publicly.

Website data

This informational website does not intentionally request cloud-storage credentials, collect backup file contents, or provide a form for submitting personal information. GitHub Pages hosts this website; GitHub may process technical information as part of operating and securing its hosting service under its own policies.

Third-party services

The backup workflow connects to services selected by the account owner, such as Microsoft OneDrive and Google Drive. Those providers process information under their own privacy terms and policies. This project does not control their data practices.

Data retention and deletion

Files retained in the cloud destinations are controlled by the account owner and the rclone commands or schedule they configure. The account owner can revoke the application's access through the relevant provider account settings and remove local rclone configuration files when appropriate.

Changes and contact

This policy may be updated if the backup workflow or its practices change. For questions about the configuration, contact the person who operates it.
