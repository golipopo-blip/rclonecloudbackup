Rclone Cloud Backup

Information about a cloud backup workflow that uses rclone to copy files between cloud storage services.

About this project

Rclone Cloud Backup is the name used for a personal backup configuration built with rclone. The intended workflow copies selected folders from a OneDrive account to separate Google Drive destinations.

The source OneDrive is treated as the master copy. Google Drive destinations are intended to serve as one-way mirrors or backups. The configuration and schedule are managed by the account owner on their own computer.

How it works

Rclone is run by the account owner on their device. It connects to cloud storage accounts that the owner has explicitly configured and authorized. Depending on the operation and provider capabilities, file data may be transferred directly between providers or through the owner's device.

This website is an informational page. It does not provide a hosted backup service or operate the rclone process.
